# CLAUDE.md

## Decision & planning docs

- [`docs/decisions/`](docs/decisions/README.md) — ADRs for significant, hard-to-reverse technical decisions (one file per decision, numbered sequentially).
- [`docs/plans/`](docs/plans/README.md) — per-feature implementation plans, one file per feature. Each plan has a Decisions table: real design forks are surfaced to Paul individually and confirmed *before* implementation, logged with the date.

When planning a non-trivial feature, use these templates rather than deciding design forks unilaterally.
